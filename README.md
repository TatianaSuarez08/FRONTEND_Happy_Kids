# frontend
 Frontend del Proyecto

## 📌 Descripción
Este repositorio contiene el desarrollo del frontend de la aplicación, encargado de la interfaz gráfica y de la interacción con los usuarios. Su objetivo es ofrecer una experiencia intuitiva, moderna y responsiva para acceder a las funcionalidades del sistema.

## 🚀 Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap
- React (si aplica)
- Node.js (si aplica)
